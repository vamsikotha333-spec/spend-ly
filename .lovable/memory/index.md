# Project Memory

## Core
Project "FinTracker Pro" using Supabase for real-time shared transaction storage.
Data and summaries are constrained to Oct 2025 - Dec 2026.
Colors: Income (green), Expense (red), Savings (blue). Fixed left sidebar with dark navy background.
Home page is the default landing page (/) with command center. Dashboard moved to /dashboard.
